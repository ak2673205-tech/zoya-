# ANU - Android AI Voice Assistant 🎙️⚡

ANU ek advanced, intelligent voice assistant aur device automation app hai jo Hindi, Hinglish aur English commands ko samajhkar real-time tasks execute karta hai.

---

## 🚀 GitHub Actions se Debug APK kaise download karein:

Is repository mein **GitHub Actions Workflow** (`.github/workflows/build-apk.yml`) pre-configured hai. 

Jab bhi aap is project ko GitHub par push karenge:
1. GitHub Actions automatically Android build process start karega.
2. `app-debug.apk` compile ho jayega.
3. Aap GitHub repository ke **Actions** tab se **ANU-Assistant-Debug-APK** direct download kar sakte hain!

### Step-by-Step Guide:

1. **AI Studio se GitHub par push karein:**
   - AI Studio ke top-right ya settings menu se **"Push to GitHub"** / **"Export to GitHub"** par click karein.
   - Apna GitHub repository select ya create karke push karein.

2. **GitHub Actions Tab kholein:**
   - Apne GitHub repository page par jayein.
   - Upar **"Actions"** tab par click karein.
   - **"Build & Release Debug APK"** workflow par click karein (aap ise manually **"Run workflow"** button daba kar bhi run kar sakte hain).

3. **APK Download karein:**
   - Build complete hone ke baad run summary page par scroll karein.
   - **Artifacts** section mein aapko **`ANU-Assistant-Debug-APK`** file mil jayegi.
   - Click karke download karein aur phone par install karein!

---

## 📱 AI Studio se Direct APK download karne ka tareeka:
Aap bina GitHub ke bhi AI Studio interface se direct APK export kar sakte hain:
- AI Studio menu / settings icon par jayein.
- **Export** ya **Generate APK** option select karein.
- APK file aapke computer/device par turant download ho jayegi.

## 🛠️ Features
- **Voice Assistant**: Natural Hindi & English speech recognition aur smooth Text-to-Speech.
- **AI Brain**: Google Gemini API powered intelligent reasoning aur contextual memory.
- **Device Control**: Flashlight, volume, battery status, settings deep links.
- **App Automation**: Installed apps launch, YouTube search, WhatsApp messaging, contacts call.
- **Background & Overlay**: Floating ANU orb aur foreground voice service.
